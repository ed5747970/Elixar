Elixar User Guide

The cure for a full C: drive · made by Elisar · version 2.0.0

Elixar frees space on drive C: safely. It shows what fills the drive, from Critical to Safe, and removes only what you choose.

At a glance

Start on the Dashboard to see what fills C:, then clean in the Cleaner; the other tabs handle apps, deeper tools, your phone and schedules. Press F1 in Elixar any time to open this guide.

Getting started

Unzip Elixar.zip anywhere (for example your Desktop). Elixar needs only Windows 10 or 11; nothing else to install.

  1. Check the download (optional). Open a Command Prompt in the folder and run certutil -hashfile Elixar.exe SHA256. The result must match SHA256.txt.
  2. Run the safe self-test. Double-click “Run self-test (safe).bat”. It works only in its own Temp folder, measures your real items without deleting anything, opens the window with cleaning switched off, and saves selftest-report.txt. If Windows shows “Windows protected your PC”, click More info › Run anyway.
  3. Open Elixar. Double-click Elixar.exe and click Yes on the Windows prompt (it needs administrator rights to clean Windows folders).
  4. Clean. Start on the Dashboard to see what fills C:, then go to the Cleaner tab, click a row to read what it removes, tick what you want and click “Clean selected”. Nothing is deleted before you confirm, and a restore point is made first.

Dashboard

The Dashboard opens first and shows what fills C:, grouped from Critical to Safe. It never deletes anything.

  • Drive bar: C: split into Critical, Caution, Review, Safe, other used and free space.
  • Four cards: how many GB sit in each level and what to do about it.
LevelMeaningWhat to do
CriticalWindows, Program Files, the page fileNever delete by hand; uninstall apps in the Apps tab
CautionLeftovers such as Windows upgrade mediaRead the note first; kept in Undo for 7 days
ReviewYour files, Downloads, the Recycle BinYour decision
SafeCaches and temp filesRebuilt automatically; clean any time
  • Everything on C: every known location, biggest first, with its share of used space. A folder inside another listed folder is never counted twice.
  • Find largest files: scans the whole drive (2 to 5 minutes, read-only) and lists files over 50 MB from Critical to Safe. Double-click a file to show it in its folder; right-click › Uninstall when it belongs to an app.
  • Folder drill-down: double-click a folder row or click “Explore C:\” to see what is inside, biggest first. Backspace goes up. This also explains “Other used”.
  • F5 or Refresh measures again; it also refreshes after every clean.
  • Space trend: free space over time and a forecast like “C: loses 5 GB a month, full around October 2027”. Elixar records one reading a day (each scan and the daily low-space check), so the chart fills in over a few days.
  • Disk health: the button turns orange (“Disk health: check”) or red (“back up now!”) when a drive needs attention. Click it to see why.
  • Folder map: boxes sized by the space they use and coloured by level (red critical, orange caution, blue review, green safe). Click a folder to go inside; Backspace goes back.

Cleaner

The Cleaner lists 43 items in four groups; tick what you want and click “Clean selected”. Click any row to read exactly what it removes. Free space for me... asks how many GB you want back and ticks the safest items that reach it (Caution items and the Recycle Bin only if you allow them; privacy items never).

GroupTicked for you?Examples
SafeYes (11 items)Temp files, Windows Update downloads, Delivery Optimization, DirectX and NVIDIA shader caches, thumbnail cache, error reports, crash dumps, Chrome and Edge cache, Stremio cache; not ticked: Discord, Teams, Telegram, WhatsApp, Zoom, Epic, EA, Steam, other browsers, VS Code
ReviewNoRecycle Bin, Spotify cache, NuGet packages, Docker unused data
CautionNeverPrevious Windows installation (Windows.old, often 15-30 GB, removed with Windows’ own Disk Cleanup), Windows upgrade media ($GetCurrent), recovery update leftovers ($WinREAgent), old Adobe Reader updates, NVIDIA app update downloads; moved to Undo for 7 days
PrivacyNeverBrowsing history and cookies (Chrome, Edge, Brave), Firefox cookies, recent files and jump lists, typed history, clipboard, DNS cache
  • Open apps: if an app whose cache is ticked is open, Elixar asks before closing it.
  • Restore point: made before cleaning unless you untick it.
  • Rescan (F5): measures again. The Change column shows how much each item grew (orange) or shrank (green) since the last scan.
  • Privacy items never touch saved passwords, bookmarks or logins, and are never part of the weekly clean.

Apps

Uninstalling apps you don't use is the safe way to shrink the Critical part of C:.

Programs: every installed program with its size on disk and when it was last used (from Windows' own records). Orange means no use found in 90 days. Click a column to sort. “Uninstall...” runs the app's own uninstaller, the same one Windows uses; apps installed for your account only are uninstalled with your normal rights, not as administrator.

Tools

The Tools tab has seven inner tabs for deeper jobs.

Disk health

Reads the health, wear and error counters your drives keep about themselves (the same data Windows uses) and tells you, in plain words, before a drive fails. It only reads: nothing is written to any drive, nothing is downloaded, nothing is sent anywhere, and serial numbers are not read.

ResultWhenWhat to do
HealthyWindows says the drive is fine and nothing below appliesNothing
Needs attentionWindows reports a warning; under 20% of an SSD's rated write life left; errors the drive couldn't fix; running hot (55 °C for a hard disk, 70 °C for an SSD)Keep a recent backup and check again in a few days (or let a hot PC cool down)
May fail soonWindows says unhealthy; the drive's own S.M.A.R.T. check predicts failure; its rated write life is used upBack up your files today, then replace the drive
UnknownThe drive shares nothing (common for USB drives)Never shown as healthy when Elixar can't tell

Wear, temperature and error counts need administrator rights, which Elixar normally has. The daily low-space check also checks the drives and shows a notification: every day while a drive may fail soon, once a week while it needs attention.

Drivers

Shows this PC's hardware (CPU, graphics, motherboard, disks, network) and finds drivers it doesn't need.

Drivers a device uses, drivers Windows needs to start, and printer and extension drivers are never offered. Each removed driver is backed up to Undo first.

Startup

Everything that starts with Windows, checked for who signed it and where it runs from. “Needs a look” flags hidden scripts, programs in Temp or Downloads, and broken or missing signatures. Turn entries off or on (the same switch as Task Manager), remove leftovers whose program is gone (kept in Undo), or scan any of them with Microsoft Defender. Not signed doesn't mean harmful; many small tools aren't signed.

System space

  • Hibernation file: hiberfil.sys is often 6-16 GB. “Make smaller” keeps Fast Startup but drops Hibernate; “Turn off” frees all of it; “Turn back on” restores it.
  • WinSxS: see what DISM can really clean, then clean it.
  • Reserved storage: turn off to free about 7 GB (turn it on again before big updates).
  • Restore points: see how much space they use and set a limit.
  • Compact OS: Windows compresses its own files (about 2 GB), reversible.
  • WSL and Docker disks: shrink virtual disks that only ever grow.

Move off C:

Moves Downloads, Documents, Pictures, Videos, Music and Desktop to your second drive the way Windows does it (Properties › Location): every file is copied and checked, then Windows is pointed at the new place, then the old copies are deleted. “Move back to C:” undoes it. Folders kept in sync by OneDrive are left to OneDrive. Steam games on C: are listed by size; Steam moves them itself (Settings › Storage › Move). Buttons open Windows’ settings for moving Store apps and for saving new files on another drive.

Duplicates

Finds files with exactly the same content in Documents, Pictures, Videos, Music, Desktop, Downloads or folders you add. Windows, apps and AppData are never searched. Extra copies go to the Recycle Bin and at least one copy of each file is always kept.

Undo

Caution items, removed drivers and removed startup entries are kept here for 7 days, on your second drive when there is one, so C: space is freed right away. Restore puts them back exactly where they were; after 7 days they are deleted for good.

Phone

The Phone tab cleans an Android phone over a USB cable and moves big photos and videos off an iPhone.

Android setup (once): on the phone open Settings › About phone and tap “Build number” 7 times (Samsung: Software information › Build number; Xiaomi: OS version). Then turn on Developer options › USB debugging, plug in, unlock and tap Allow. Elixar uses Google's free Android tools; “Get Android tools” downloads them and checks Google's signature.

Android tabWhat it does
CleanSafe: cache of every app (you stay signed in), gallery thumbnails, WhatsApp statuses you watched. Review (copied to this PC first): deleted photos in the trash, WhatsApp media you sent, Telegram downloads, old .apk files
AppsPre-installed extras you can remove for your account only (“Put back” restores them); your own apps by size and last use, flagged after 60 days unused
Big filesYour biggest videos and files; “Move to PC” copies each, checks the size, then deletes it from the phone

iPhone setup (once): install “Apple Devices” from the Microsoft Store, plug in, unlock and tap Trust. Elixar shows the storage and moves big photos and videos to this PC. Apple doesn't let a PC clean apps, so the Clean tab lists what to clean on the iPhone itself (Recently Deleted, Offload Unused Apps, WhatsApp storage and more). After moving, empty Photos › Recently Deleted to free the space.

Copies go to a “Phone backup” folder on your second drive, or in Pictures.

Automation

Two schedules run through Windows Task Scheduler even when Elixar is closed; click Save to turn them on or off.

  • Low-space alert: a Windows notification when C: drops under the limit you choose (default 15%), checked daily and a few minutes after you sign in. The same check warns you when a drive's health gets worse.
  • Weekly auto-clean: cleans only the 11 default Safe items on the day and time you choose. Never Caution items, the Recycle Bin, browser caches, privacy items or DISM. Open apps are skipped, never closed, and a notification shows what was freed.
Schedules start the protected copy in C:\Program Files\Elixar. After updating Elixar, open Automation and click Save once so they use the new version.

Settings and updates

Open the Settings tab (or click Settings in the footer). Pick a language and a theme, then click Apply and restart Elixar: Elixar restarts for a moment in the new look. The small picture next to the theme choices shows what it will look like.

  • Language: English or Hebrew (the window is laid out right to left). Some live status lines stay in English.
  • Theme: follow Windows, light or dark.
  • Install Elixar on this PC: adds it to the Start menu and to Windows’ installed apps list (with Uninstall), in C:\Program Files\Elixar.
  • Check for updates: once Elixar is published on GitHub, it checks for a new version (also quietly once a week). An update is installed only if it is signed with Elisar’s key and every file matches its fingerprint.

Email reports

Elixar can email you, from your own Gmail to yourself: the weekly auto-clean report (what was cleaned, how much it freed, what is left for you to decide), alerts (C: almost full, a drive that may fail) and a weekly summary (free space and its trend, disk health, the biggest things you can delete).

  1. One-time setup (about 10 minutes): Settings › Email reports › “Set up Google sign-in”. Elixar has no server, so you register it in your own Google account as a small private app (Gmail API on, permission “send email” only, published, Desktop app client) and choose the file Google gives you. The window lists every step.
  2. Sign in with Google. Your browser opens Google's own page. Google says “hasn't verified this app” because the app is yours: click Advanced › Go to Elixar, and allow “Send email on your behalf”. A test email arrives.
  3. Tick the emails you want and click Save email settings. A daily check (at the time you choose) sends alerts and the weekly summary; the weekly clean sends its own report.

Settings shows how the last email went (“Last email: Sun 18 Oct 09:00 – Your weekly Elixar summary ✓”). The daily check also confirms the Google sign-in still works: if Google ever signs Elixar out, the line turns red and Windows shows a reminder (once a day) to sign in again, so emails never stop silently. The weekly summary includes a chart of free space on C: over the last 8 weeks, drawn on your PC and carried inside the email.

QuestionAnswer
Can Elixar read my mail?No. It only has Google's “send email” permission. It never sees your password.
Who gets the emails?Only the address you signed in with. Elixar can't send to anyone else.
What's in them?Categories and sizes only, never file names or folders, and never a link. To delete anything, open Elixar on your PC. An email asking you to click or sign in is not from Elixar.
Where is the sign-in kept?Encrypted for your Windows account, in a folder only administrators can open.
How do I stop it?Untick the emails, or click Sign out (Google cancels the permission). Uninstalling Elixar also signs out.

Email cleaning (Email tab)

Finds what you can clean in your Gmail and moves what you pick to Gmail's Trash. It is off until you allow it: sign in first (Settings › Email reports), then on the Email tab click “Allow Elixar to check my Gmail”. Elixar explains what it will and won't do and asks you; only then does Google ask for the permission.

Security

Elixar runs as administrator, so since 1.7 it guards against a virus with normal rights tricking it into doing admin work.

RiskProtection
A virus swaps Elixar.exe and the weekly schedule runs it as adminSchedules run a copy in Program Files, which only admins can change
A fake backup planted in Undo gets restored as adminThe Undo folder is locked to admins; anything else in it is ignored; Restore never writes into Windows' folders
A link planted in Temp redirects deletion into WindowsEach file is checked for its real location while held open, then deleted; System32, drive roots and your main folders are never deleted
A fake “powershell.exe” planted next to a downloaded Elixar.exe runs as adminSince 1.9, Windows tools are always started from the Windows folder by their full path
Swapped Android tools or uninstall commands run as adminGoogle's signature is checked before the Android tools run; your account's uninstallers run without admin rights

To check your copy, click “Verify this copy” in the footer: it shows Elixar's SHA-256 fingerprint to compare with SHA256.txt, and the state of the protected copy and the Undo folder. Elixar is not an antivirus.

The blue “Windows protected your PC” box

Windows shows it for downloaded programs that aren't signed with a paid certificate. Click More info › Run anyway once, then open the Settings tab and click Install Elixar on this PC. From then on, start Elixar from the Start menu: the installed copy in Program Files carries no “downloaded” mark, so the blue box doesn't come back, and signed updates go straight into it. Windows still asks for administrator rights (the usual Yes/No prompt) each time.
